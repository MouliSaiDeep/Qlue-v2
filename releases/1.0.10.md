# Qlue 1.0.10

- Improved interview transcription with AWS streaming, earlier microphone preparation, noise filtering and automatic answer submission.
- More specific, evidence-based feedback with clearer explanations, fewer repeated points and an interactive radar score breakdown.
- Restored the stable feedback summary and Q&A layout, refined profile preferences and accelerated history-card animations.
- Added secure password recovery, locked premium voice browsing and Ruth as the default voice.
- Hide abandoned interviews with no accepted answers from history while preserving genuine zero-score attempts.
- Added recovery controls, dependency updates, feedback evaluation tools and release verification checks.
- Backend source includes event-driven processing and on-demand audio hosting to reduce idle costs. The daily limit remains ten interviews per user.

Android package: `com.qlue.sloths1`; version `1.0.10`, build `10010`.
The APK retains AWS transcription and the existing release signing certificate.
Backend source publication does not itself deploy AWS changes. Device acceptance
and human scoring calibration remain separate from automated verification.

Pre-push verification: 618 backend tests, 269 Flutter tests and 31 audio-gateway
tests passed. Flutter static analysis passed, and the backend production
dependency audit reported no vulnerabilities. The release workflow performs
its own checks before publishing the signed APK.
